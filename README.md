# Hospital Management System | SQL Project

## Overview
A Hospital Management System developed using MySQL to manage hospital operations through a structured relational database.

## Features
- Patient and doctor management
- Department management
- Appointment scheduling
- Room and admission management
- Medicine and prescription management
- Billing and payment management
- Primary and foreign key constraints
- SQL views for reporting
- Stored procedures for data retrieval

## Database Components
- 11 original tables
- 3 SQL views
- 2 stored procedures
- Additional columns and validation constraints

## Technologies Used
- MySQL 8.0
- MySQL Workbench
- SQL

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Download the final SQL script.
3. Open the script in MySQL Workbench.
4. Execute the script.
5. Explore the tables, views, and stored procedures.

## Project Structure
- `Hospital_Management_System_Final.sql` – Complete database script.
- `screenshots/` – Project execution screenshots.
- `original/` – Original database dump, if included.
